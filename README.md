# Mon chemin
App web privée : podcasts de 5 min + quiz pour les cours de Tawhid et de Fiqh.

## Mettre en ligne (GitHub Pages)
1. Envoyer ces fichiers dans le dépôt GitHub `mon-chemin`.
2. Sur GitHub : Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)`, Save.
3. Ouvrir https://aceyoune-sys.github.io/mon-chemin/ sur l'iPhone dans Safari > bouton Partager > « Sur l'écran d'accueil ».
